# Changelog

All notable changes to QuickSign are logged here.

## v1.0.0-beta.1 — 2026-07-20

Initial Reddit beta release.

### Added
- Coffee shop, hospital, and classroom learning scenarios (24 signs total)
- Rule-based sign verification with a trained ML classifier as a veto-only disambiguation layer
- Lessons, Practice, Story mode, and Speed Challenge
- Real-time multiplayer: Duel (1v1) and Room (up to 4 players)
- Streaks, XP, gold, cosmetics shop, achievements, leaderboards, friends
- In-app feedback flow and an owner-only admin/beta metrics dashboard
- Production-grade PostHog analytics (privacy-first: no session replay, anonymous by default,
  user-controlled opt-out) with emergency kill switches for camera/classifier/multiplayer/shop
- Zippy mascot, onboarding flow, camera framing guide with live hand-skeleton overlay
